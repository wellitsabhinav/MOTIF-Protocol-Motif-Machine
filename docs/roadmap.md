# Roadmap

- M0: executable model, SPI target, UART receive, framing and guardian tests.
- M1: I²C target behavior, motif accounting and sequential reference.
- M2: RTL core and model correspondence for an integrated SPI/UART subset.
- M3: synthesis and early CMOS5L physical qualification of that subset.
- M4: further protocol RTL coverage and complete submission integration.
